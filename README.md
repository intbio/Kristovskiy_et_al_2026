# Сборка комплексов из двух Cas-белков на ДНК

Модуль собирает структурную модель, в которой **два Cas-белка сидят на одной молекуле ДНК**
на заданном расстоянии между PAM-сайтами, и меряет геометрию получившейся пары.

Вопрос, на который он отвечает: на каком расстоянии окажутся функциональные концы двух
белков при разном разносе сайтов посадки. Это нужно, когда между двумя Cas должно что-то
произойти — сшивка доменов, сближение концов гРНК, работа линкера.

Комплекс собирается из экспериментальных структур тройных комплексов
Cas-белок — направляющая РНК — ДНК: две структуры стыкуются через фрагмент линкерной ДНК,
вырезанный из ансамбля конформеров. Рассматриваются три взаимные ориентации белков —
PAM-in (PAM-сайты обращены друг к другу), PAM-out (смотрят наружу) и PAM-direct
(смотрят в одну сторону).

Что меряется в собранной модели:

| параметр | что это |
|---|---|
| `"3'"` | расстояние между 3′-концами двух гРНК |
| `'C'` | между C-концами белков |
| `'N'` | между N-концами белков |

Плюс проверка на стерическое столкновение белков друг с другом и проверка того, не идёт ли
измеряемая прямая сквозь структуру комплекса.

## Установка

Нужен Python 3.12.

```bash
git clone https://github.com/intbio/Kristovskiy_et_al_2026.git
cd Kristovskiy_et_al_2026
python3.12 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Для работы в ноутбуке зарегистрируйте ядро:

```bash
python -m ipykernel install --user --name dcas9 --display-name "Python 3.12 (dCas9)"
```

Версии, на которых модуль проверен: Python 3.12.15, numpy 2.5.3, scipy 1.18.1,
MDAnalysis 2.10.0, matplotlib 3.11.2, nglview 4.0.1, pypdb 2.11.

## Ансамбли конформеров ДНК

Два ансамбля по 10 000 конформеров двуцепочечной ДНК длиной 40 и 100 пар оснований —
это 4.3 ГБ, поэтому в git они не лежат и прикреплены к релизу отдельными архивами.
**Без них сборка не работает:** линкер между двумя Cas-белками вырезается именно из них.

Скачайте архивы в корень репозитория и распакуйте:

```bash
REL=https://github.com/intbio/Kristovskiy_et_al_2026/releases/download/v1.0
curl -L -O $REL/pdb_files_40.tar.xz
curl -L -O $REL/pdb_files_100.tar.xz

shasum -a 256 pdb_files_40.tar.xz pdb_files_100.tar.xz   # сверьте с таблицей ниже

tar -xJf pdb_files_40.tar.xz
tar -xJf pdb_files_100.tar.xz
```

Должно получиться так — папки лежат рядом с модулем:

```
Kristovskiy_et_al_2026/
├── cas_complex.py
├── pdb_files_40/     0000.pdb .. 9999.pdb   (ДНК по 40 п.н.)
└── pdb_files_100/    0000.pdb .. 9999.pdb   (ДНК по 100 п.н.)
```

Если нужен только короткий линкер (разнос PAM-PAM до 37 п.н.), достаточно ансамбля
на 40 п.н. — ансамбль на 100 п.н. берётся автоматически для больших разносов.

| архив | размер | распакованный | SHA-256 |
|---|---|---|---|
| `pdb_files_40.tar.xz` | 116 МБ | 1.2 ГБ | `c92a6e0f30feca6d21a389b6f131d789ce6f0d069dd6a0d4134a71f784702f70` |
| `pdb_files_100.tar.xz` | 291 МБ | 3.1 ГБ | `bf2c2e48252e6f860ed5fd3dd4608cd47a076ccb075d18b2d176dfa25a86b3cd` |

Последовательность ДНК в обоих ансамблях — повтор додекамера Дрю—Дикерсона
(CGCGAATTCGCG); конформеры различаются изгибом спирали, и за счёт этого на каждом разносе
PAM-PAM получается не одна модель, а распределение.

## Структуры Cas-белков

Структуру можно задать двумя способами:

- **четырёхсимвольным PDB ID** — модуль скачает её из RCSB PDB сам (через `pypdb`);
- **путём к локальному файлу** в формате PDB.

Сами структуры в репозиторий не включены: они воспроизводимы по PDB ID. Проверялись
SpCas9 (5Y36, 4UN3, 5F9R, 7S4U, 7S4X, 6O0Y), SaCas9 (5CZZ, 5AXW). Оба белка задаются
независимо, так что финальный комплекс может быть как гомодимером, так и гетеродимером.

## Быстрый старт

```python
from cas_complex import *

# два SpCas9 из 5Y36, ориентация PAM-out, разнос PAM-PAM 60 п.н.
models = build_models('SpCas9', 'SpCas9', '5Y36', '5Y36', 2, [60], 0)
model = models[60]

get_dist(models, "3'")          # расстояние между 3'-концами гРНК, A
check_clashing(model)           # столкнулись ли белки
check_dist_path(model, "3'")    # не идёт ли прямая сквозь структуру
check_model(model)              # полная диагностика собранной модели
show_dist(model, "3'")          # посмотреть расстояние в nglview

# статистика по диапазону разносов: на каждый разнос по 5 сборок
fig, stats = plot_dist('SpCas9', 'SpCas9', '5Y36', '5Y36', 2,
                       range(42, 100, 4), params="3'", repeats=5)
```

Ориентация задаётся числом: `0` — PAM-direct, `1` — PAM-in, `2` — PAM-out.
Последний аргумент `build_models` — флаг сохранения: `1` положит модели
в `Cas_Cas_complex/<ориентация>/`.
